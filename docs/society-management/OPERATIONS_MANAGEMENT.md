# OPERATIONS_MANAGEMENT.md — Internal Operations & Task Management

## 1. Overview
Coordinates daily administrative tasks, field recovery drives, audit inspections, and member grievance resolution.

## 2. Task Lifecycle
- `OPEN` -> `ASSIGNED` -> `IN_PROGRESS` -> `ON_HOLD` -> `COMPLETED` / `CANCELLED`.
- Tasks include priority levels (Low, Medium, High, Urgent), due dates, assigned staff, and comment logs.
