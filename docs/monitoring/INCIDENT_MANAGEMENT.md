# Enterprise Incident Management Workflow Manual

## ১. ইনসিডেন্ট লাইফসাইকেল (Incident Lifecycle Stages)

```
[শনাক্তকরণ (Detection)]
        │
        ▼
[স্বীকারকরণ (Acknowledgment)] ────> রেসপন্ডার নিয়োগ (Assign Responder)
        │
        ▼
[তদন্ত (Investigation)] ──────────> প্রাথমিক ট্রায়াজ ও প্রভাব নির্ধারণ
        │
        ▼
[নিয়ন্ত্রণ (Containment)] ─────────> হটফিক্স, রোলব্যাক বা ট্রাফিক ডাইভারশন
        │
        ▼
[পুনরুদ্ধার (Recovery)] ──────────> সেবা পুনরায় স্বাভাবিক অবস্থায় প্রত্যাবর্তন
        │
        ▼
[সমাধান (Resolution)] ────────────> গ্রাহক ও ম্যানেজমেন্ট নোটিফিকেশন
        │
        ▼
[রুট কজ অ্যানালাইসিস (RCA)] ───────> ৫-Why অ্যানালাইসিস ও স্থায়ী সমাধান নথিভুক্তকরণ
```

## ২. ইনসিডেন্ট গুরুত্ব মাত্রা (Incident Severity Matrix)
- **SEV-1 (Critical)**: সম্পূর্ণ সিস্টেম অথবা সমস্ত সমিতির লেনদেন বন্ধ। এসএলএ রেসপন্স টাইম: < ১৫ মিনিট।
- **SEV-2 (Major)**: কোনো একটি প্রধান ফিচার (যেমন: নগদ আদায় বা লোন অনুমোদন) সম্পূর্ণ অচল। রেসপন্স টাইম: < ১ ঘণ্টা।
- **SEV-3 (Minor)**: কোনো অ-আর্থিক ফিচার (যেমন: নোটিশ প্রিন্ট বা ফটো আপলোড) সাময়িক ব্যর্থ। রেসপন্স টাইম: < ৪ ঘণ্টা।
- **SEV-4 (Cosmetic)**: টাইপো, ইউআই ত্রুটি বা নন-ব্লকিং সমস্যা। নিয়মিত স্প্রিন্টে সমাধান।

## ৩. পোস্টমর্টেম ও আরসিএ পলিসি (Post-Mortem & RCA)
যেকোনো Sev-1 অথবা Sev-2 ইনসিডেন্ট সমাধানের ৪৮ ঘণ্টার মধ্যে একটি আনুষ্ঠানিক রুট কজ অ্যানালাইসিস (RCA) রিপোর্ট সুপার এডমিন কনসোলে জমা দিতে হয়।
