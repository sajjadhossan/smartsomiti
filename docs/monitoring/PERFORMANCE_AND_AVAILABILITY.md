# Performance & Availability Monitoring Manual

## ১. প্ল্যাটফর্মের কর্মক্ষমতা লক্ষ্যমাত্রা (Service Level Objectives - SLO)

| সেবা (Service) | লক্ষ্যমাত্রা (Target SLO) | পরিমাপের পদ্ধতি (Measurement) |
|---|---|---|
| **মাসিক আপটাইম (Uptime)** | ৯৯.৯% | এক্সটার্নাল সিন্থেটিক পিং ও হেলথচেক |
| **API লেটেন্সি (P95)** | < ২০০ মি.সে. | ক্লাউড ফাংশন ও এপিআই গেটওয়ে মেট্রিক্স |
| **Firestore রিড লেটেন্সি** | < ৫০ মি.সে. | ফায়ারস্টোর ক্লায়েন্ট SDK পারফ ট্র্যাকিং |
| **অ্যাপ্লিকেশন স্টার্টআপ টাইম** | < ১.৫ সেকেন্ড | ফ্লাটার ফার্স্ট ফ্রেম রেন্ডার কলব্যাক |
| **অফলাইন কিউ সিঙ্ক সময়** | < ৩ সেকেন্ড | ২০টি ট্রানজাকশনের ব্যাচ সিঙ্ক টাইম |

## ২. সিন্থেটিক পারফরম্যান্স ট্র্যাকিং
- সিস্টেম ব্যাকগ্রাউন্ডে নিয়মিত (প্রতি ৬০ সেকেন্ডে) হেড রিকোয়েস্ট পাঠিয়ে রাউন্ড-ট্রিপ টাইম (RTT) পরিমাপ করে।
- ব্রাউজারের লোকাল স্টোরেজ ব্যবহার নিয়মিত মনিটর করা হয় যাতে কোটা শেষ হওয়ার আগেই সতর্কবার্তা দেওয়া সম্ভব হয়।

## ৩. ড্যাশবোর্ড ও রিপোর্টিং পারমিশন
- প্ল্যাটফর্ম মাস্টার এডমিন ও ডেভঅপস ইঞ্জিনিয়াররা ক্লাউড অঞ্চলের ইনফ্রাস্ট্রাকচার ব্যবহার নিরীক্ষা করতে পারবেন।
- কোনো সমবায় সমিতি অন্য কোনো সমিতির ইনফ্রাস্ট্রাকচার পারফরম্যান্স মেট্রিক্স দেখতে পারবে না (কঠোর টেন্যান্ট আইসোলেশন)।
