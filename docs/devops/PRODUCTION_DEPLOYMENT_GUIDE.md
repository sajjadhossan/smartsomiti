# Production Multi-Environment Deployment Guide

## ১. এনভায়রনমেন্ট বিভাজন (Environment Separation)
1. **Development (`dev`)**: স্থানীয় ডেভেলপার টেস্ট ও ইউনিট টেস্টিং।
2. **Staging (`staging`)**: ক্লাউড স্যান্ডবক্স, ব্যাকআপ রিস্টোর মহড়া ও ক্লায়েন্ট প্রিভিউ।
3. **Production (`prod`)**: রিয়েল ফাইন্যান্সিয়াল ট্রানজাকশন ও সক্রিয় সমবায় সমিতি কার্যক্রম।

## ২. প্রি-ডিপ্লয়মেন্ট চেকলিস্ট
- [x] সমস্ত ইউনিট টেস্ট শতভাগ পাস হয়েছে (`100% PASS`).
- [x] ফায়ারস্টোর ও স্টোরেজ সিকিউরিটি রুলস অডিট সম্পন্ন।
- [x] প্রি-ডিপ্লয়মেন্ট স্ন্যাপশট ব্যাকআপ সম্পন্ন।
- [x] রোলব্যাক টার্গেট ভার্সন প্রস্তুত রাখা হয়েছে।
- [x] মেইনটেন্যান্স গেটওয়ে ও বাইপাস টোকেন যাচাইকৃত।
