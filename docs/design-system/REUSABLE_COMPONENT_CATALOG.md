# Reusable Component Catalog Specification

## ১. কোর ইউআই কম্পোনেন্টস (Core UI Components)
1. **AppButton**:
   - ভেরিয়েন্ট: Primary (Emerald), Secondary (Sky Blue), Danger (Crimson), Outline, Ghost.
   - স্টেটস: Default, Hover, Focused, Disabled, Loading (ইনলাইন স্পিনারসহ).
   - অ্যাক্সেসিবিলিটি: মিনিমাম ৪৪x৪৪px ক্লিক টার্গেট ও কীবোর্ড ফোকাস রিং.
2. **StatCard (KPI Widget)**:
   - আইকন, লেবেল, বোল্ড নিউমেরিক ভ্যালু, শতাংশ ট্রেন্ড ইন্ডিকেটর এবং কালার-কোডেড লেফট বর্ডার স্ট্রাইপ.
3. **AppTextField**:
   - ফ্লোটিং বা ফিক্সড লেবেল, অপশনাল হেল্পার টেক্সট, ইনলাইন ভ্যালিডেশন এরর, প্রিফিক্স/সাফিক্স আইকন ও ক্লিয়ার বাটন.
4. **AppModalDialog**:
   - রেসপনসিভ সেন্ট্রালাইজড ডায়ালগ, এস্কেপ কীবোর্ড ডিসমিস, হেডার ক্লোজ বাটন ও ব্যাকড্রপ ব্লার.
5. **StatusBadge**:
   - কালার-কোডেড পিল বাটন (যেমন: `সক্রিয়`, `অপেক্ষমান`, `বাতিলকৃত`, `স্থগিত`).
6. **ResponsiveDataGrid**:
   - ডেস্কটপে ফুল টেবিল ভিউ ও মোবাইলে কমপ্যাক্ট কার্ড ভিউতে অটো-সুইচ মেকানিজম.
