# Responsive Breakpoints & Adaptive Layouts Specification

## ১. ব্রেকপয়েন্ট ডেফিনেশন (Screen Breakpoints)

| ব্রেকপয়েন্ট | প্রস্থ পরিসীমা (Width) | ডিভাইস ক্যাটাগরি | নেভিগেশন স্ট্রাকচার |
|---|---|---|---|
| **Mobile Small (`xs`)** | < ৩৬০px | এন্ট্রি-লেভেল স্মার্টফোন | টপ কম্প্যাক্ট বার + বটম শিট ড্রয়ার |
| **Mobile Standard (`sm`)** | ৩৬০px - ৬৩৯px | স্ট্যান্ডার্ড স্মার্টফোন | ফিক্সড হেডার + বটম ড্রয়ার মেনু |
| **Tablet (`md`)** | ৬৪০px - ১০২৩px | ট্যাব / আইপ্যাড | কলাপসিবল আইকন সাইডবার |
| **Desktop Standard (`lg`)**| ১০২৪px - ১৪৩৯px | ল্যাপটপ / ডেস্কটপ | এক্সপ্যান্ডেড সাইডবার + মাল্টি-কলাম গ্রিড |
| **Desktop Large (`xl`)** | >= ১৪৪০px | ওয়াইড মনিটর | সর্বোচ্চ কনটেইনার উইডথ ১৪৪০px সেন্টারড |

## ২. মোবাইলে হরাইজন্টাল ওভারফ্লো প্রতিরোধ
- সমস্ত টেবিল অনুভূমিক স্ক্রোল (`overflow-x: auto`) অথবা স্ট্যাকড কার্ড ভিউতে অটো-কনভার্ট হবে।
- কোনো ফর্মে বা কার্ডে অনুভূমিক স্ক্রোলবার থাকবে না।
