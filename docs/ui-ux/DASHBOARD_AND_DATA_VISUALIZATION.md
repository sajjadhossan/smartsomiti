# Dashboard & Data Visualization UX Specification

## ১. ড্যাশবোর্ড লেআউট নীতি
- **উচ্চ-মূল্য মেট্রিক্স উপরে**: মোট সঞ্চয়, ঋণ স্থিতি, আজকের আদায় ও ক্যাশ ইন হ্যান্ড সবার প্রথমে কার্ড আকারে প্রদর্শিত হবে।
- **চার্ট রেন্ডারিং**: বার চার্ট ও লাইন চার্টে স্পষ্ট অক্ষ লেবেল, বিডিটি কারেন্সি সিম্বল (`৳`) এবং বাংলা সংখ্যার সাপোর্ট থাকবে।
- **উইজেট কাস্টমাইজেশন**: সুপার এডমিন ও সমিতি এডমিন রোল অনুযায়ী কোন উইজেট প্রদর্শিত হবে তা নিয়ন্ত্রণ করতে পারবেন।

## ২. শূন্য ডাটা ও লোডিং স্টেট
- চার্ট লোড হওয়ার সময় সুন্দর পালসিং স্কেলিটন বা স্পিনার প্রদর্শিত হবে।
- নতুন সমিতির ক্ষেত্রে ফাঁকা চার্ট না দেখিয়ে উৎসাহব্যঞ্জক এম্পটি স্টেট গাইড দেখানো হবে।
